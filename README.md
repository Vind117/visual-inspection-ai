# 🔍 Vision Inspection AI — Quality Control Toolkit

A production-ready computer vision inspection application built with **Python, PyTorch, Ultralytics YOLOv8, OpenCV, and Streamlit**. Designed to simulate automated manufacturing defect detection, real-time inference benchmarking, and compliance logging.

---

## 🚀 Features
- **Custom Defect Detection:** Trained locally on synthetic/industrial component datasets to detect surface defects (scratches, spots, cracks, dents).
- **Interactive Web Dashboard:** Built with Streamlit for seamless image uploading, confidence threshold tuning, and visual verification.
- **Real-Time Benchmarking:** Measures and logs inference latency (ms) and detection counts per frame.
- **Compliance Reporting:** Automatically generates downloadable CSV inspection logs for quality assurance workflows.

---

## 🛠️ Tech Stack
- **Deep Learning:** PyTorch, Ultralytics YOLOv8
- **Computer Vision:** OpenCV, Pillow, NumPy
- **Frontend / UI:** Streamlit, Pandas
